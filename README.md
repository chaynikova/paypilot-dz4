## Запуск
Діалогові кейси вимагають ранера з підтримкою `turns` та `invariants`, тому набір проганяється кітом заняття `paypilot-l05-eval` (тека `~/paypilot/l05`, на Windows `C:\l05`, поруч зі стендом). Покладіть `l05_dialogs.jsonl` у `sets/` кіту і виконайте:

```
docker compose run --rm eval --set l05_dialogs --gate release --profile clean --traces
```

Кейси мають `gate: release` (діалоги не входять у щоденний прогін), тому потрібен прапорець `--gate release`. Поріг згортки задає кожен кейс (`summarize_after`).
